# Python Data Structures & Basics

This project is part of the Holberton School Higher Level Programming curriculum.

It focuses on Python basics, including data structures (lists, tuples, dictionaries), functions, and simple algorithms.

## Content

- Lists and list manipulation
- Tuples and tuple operations
- Dictionaries and key/value access
- Basic loops and conditions
- Function writing and usage

## Requirements

- Python 3 (Ubuntu 20.04 LTS, python3 3.8.5)
- Code must follow pycodestyle (2.7.*)
- All files must start with:
  #!/usr/bin/python3
- All files must be executable
- No external modules allowed (unless specified in task)
- All files must end with a new line
