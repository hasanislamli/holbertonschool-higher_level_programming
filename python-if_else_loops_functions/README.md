# Python - if/else, loops, functions

This project covers basic Python concepts such as:
- if, elif, else conditions
- loops (for, while)
- functions
- using random numbers

Each script demonstrates how to use conditional statements and loops in Python.

Requirements:
- Python 3.8
- Ubuntu 20.04 LTS
- pycodestyle (PEP8)

All scripts:
- start with #!/usr/bin/python3
- are executable
- follow pycodestyle standards
