Python Network 1

This project focuses on using Python to interact with web resources using the urllib package.

The scripts perform HTTP requests, handle responses, and process data returned from web servers.

Requirements:

* Python 3.8
* Ubuntu 20.04 LTS
* All scripts must be executable
* All files must end with a new line
* Code must follow pycodestyle

Guidelines:

* Only the urllib package is allowed
* Use the with statement when making HTTP requests
* All modules, classes, and functions must be documented
* Use dictionary.get() when accessing dictionary values
* Code should not execute when imported

Objective:
The goal of this project is to understand how HTTP requests work in Python and how to handle responses properly.
